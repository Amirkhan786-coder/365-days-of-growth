# 🏦 Bank Account Management System

## 📌 Project Overview

The **Bank Account Management System** is a simple Python console application developed using **Dictionaries**. It allows users to create and manage bank accounts efficiently through a menu-driven interface.

This project demonstrates the practical use of Python dictionaries for storing and manipulating structured data.

---

## 🚀 Features

- ✅ Create New Account
- 💰 Deposit Money
- 💸 Withdraw Money
- 🔍 Search Account
- 📋 Display All Accounts
- 🗑 Delete Account
- 🚪 Exit Program

---
