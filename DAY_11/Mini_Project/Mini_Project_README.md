# 📚 Student Record Manager

## 📌 Project Overview

The **Student Record Manager** is a Python console-based application that stores student records in a text file. It demonstrates Python File Handling by allowing users to add, view, search, update, and delete student records.

---

# 🚀 Features

- ✅ Add Student
- ✅ View All Students
- ✅ Search Student
- ✅ Update Student Details
- ✅ Delete Student
- ✅ Store Records Permanently in a Text File
- ✅ Menu-Driven Interface
- ✅ Exception Handling
