# 🔐 Strong Password Generator

## 📌 Project Overview

The **Strong Password Generator** is a Python console application that creates secure and random passwords using Python's built-in **random** and **string** modules.

The user can choose the password length, and the program generates a password containing uppercase letters, lowercase letters, digits, and special characters.
