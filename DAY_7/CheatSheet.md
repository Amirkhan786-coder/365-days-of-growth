# 📌 Python Sets Cheat Sheet

## Create Set

```python
A = {1,2,3}
```

## Empty Set

```python
A = set()
```

## Add

```python
A.add(10)
```

## Update

```python
A.update([20,30])
```

## Remove

```python
A.remove(10)
```

## Discard

```python
A.discard(10)
```

## Pop

```python
A.pop()
```

## Clear

```python
A.clear()
```

## Copy

```python
B = A.copy()
```

## Union

```python
A | B
```

## Intersection

```python
A & B
```

## Difference

```python
A - B
```

## Symmetric Difference

```python
A ^ B
```

## Subset

```python
A.issubset(B)
```

## Superset

```python
A.issuperset(B)
```

## Disjoint

```python
A.isdisjoint(B)
```

## Frozen Set

```python
A = frozenset({1,2,3})
```

## Length

```python
len(A)
```
