## 📚 What I Learned Today

Today I learned how Python functions can be treated as first-class objects.

I learned that functions can be:

- Stored in variables
- Passed as arguments
- Returned from other functions
- Stored in lists and other data structures

I also learned about Higher-Order Functions, nested functions, closures and decorators.

---

## 🎯 Main Concepts I Learned

### 1. First-Class Functions

Functions in Python can be treated like other objects.

They can be passed, stored and returned.

### 2. Higher-Order Functions

A function that accepts another function or returns another function.

### 3. Nested Functions

A function defined inside another function.

### 4. Decorators

Decorators allow us to add or modify the behavior of existing functions without changing their main code.

### 5. `*args`

Used to accept multiple positional arguments.

### 6. `**kwargs`

Used to accept multiple keyword arguments.

### 7. `functools.wraps`

Used to preserve metadata of the original function.
