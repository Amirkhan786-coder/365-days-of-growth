# 🚀 DAY 03 – Mini Project

# 🎮 Project Title

## Number Guessing Game

---

# 📌 Project Overview

The **Number Guessing Game** is a beginner-friendly Python project that helps you practice:

- while loop
- if-else statements
- break statement
- User Input
- Random Number Generation
- Logical Thinking

The computer randomly selects a number, and the player has to guess it.

The program provides hints until the correct number is guessed.

# 🎮 Game Flow

```
Start Game
      │
      ▼
Generate Random Number
      │
      ▼
Take User Guess
      │
      ▼
Correct?
 ┌───────────────┐
 │               │
No              Yes
 │               │
 ▼               ▼
Show Hint     Congratulations
 │               │
 ▼               ▼
Try Again      End Game
```
