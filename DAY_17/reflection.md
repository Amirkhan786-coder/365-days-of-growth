# 🧠 WHAT I LEARNED

Today I learned the difference between an **Iterable** and an **Iterator**.

I learned how to use:

```python
iter()
````

to create an iterator and:

```python
next()
```

to retrieve values from the iterator.

I also learned about:

```text
StopIteration
```

which occurs when an iterator has no more values.

---

# 🔄 ITERATORS

I learned that an iterator produces values one at a time.

I also learned how to create custom iterators using:

```python
__iter__()
__next__()
```

This helped me understand how Python's iteration mechanism works internally.

---

# ⚡ GENERATORS

The most important concept I learned today was **Generators**.

Generators use the:

```python
yield
```

keyword to produce values one at a time.

Unlike a normal function that returns a value and ends, a generator can pause its execution and continue from the same point later.

---

# 🧠 LAZY EVALUATION

I learned about **Lazy Evaluation**.

Instead of generating all values at once, a generator creates a value only when it is required.

This can make programs more memory efficient, especially when working with large datasets.

# 📚 KEY TAKEAWAYS

### 1. Iterable

An object that can be iterated over.

### 2. Iterator

An object that produces values one at a time.

### 3. `iter()`

Creates an iterator from an iterable.

### 4. `next()`

Returns the next value from an iterator.

### 5. `StopIteration`

Indicates that there are no more values.

### 6. Generator

A special type of iterator created using `yield`.

### 7. Lazy Evaluation

Values are generated only when required.
