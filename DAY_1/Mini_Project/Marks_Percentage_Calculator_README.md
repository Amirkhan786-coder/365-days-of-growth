# 📊 Marks Percentage Calculator

## 📌 Objective

Create a simple Python program to calculate the total marks and percentage of a student.

## 🛠 Concepts Used

- Variables
- Data Types
- User Input
- Arithmetic Operators
- Formatted Output

## 📥 Input

- Student Name
- Marks of 5 Subjects

## 📤 Output

- Student Name
- Total Marks
- Percentage

## 📚 Learning Outcome

- Learned how to use variables.
- Learned user input.
- Learned arithmetic operations.
- Learned formatted output using f-strings.
