# 🎓 Student Information System

## 📌 Objective

Create a Python program to collect and display student information.

## 🛠 Concepts Used

- Variables
- Data Types
- User Input
- f-Strings
- Output Formatting

## 📥 Input

- Student Name
- Roll Number
- Branch
- College Name
- Semester
- CGPA

## 📤 Output

Displays all student details in a formatted way.

## 📚 Learning Outcome

- Learned how to store different types of data.
- Learned how to use input().
- Learned formatted printing using f-strings.
