## 1. What is Python?

### Answer

Python is a high-level, interpreted, object-oriented, and general-purpose programming language developed by Guido van Rossum in 1991.

It is known for:

- Simple Syntax
- Readability
- Large Community
- Huge Library Support
- Cross-Platform Compatibility

---

### Answer

Python is popular because:

- Easy to learn
- Easy to read
- Open source
- Large community support
- Huge collection of libraries
- Used in AI, ML, Web Development, Data Science, Automation and IoT

## 5. What is an interpreted language?

### Answer

An interpreted language executes code line by line instead of converting the entire program into machine code before execution.

Example:

Python

Advantages:

- Easy Debugging
- Faster Testing
- Immediate Output

## 6. What is a variable?

### Answer

A variable is a named memory location used to store data.

Example:

```python
name = "Amir"
age = 19
```

---

## 7. Why do we use variables?

### Answer

Variables help us:

- Store Data
- Reuse Data
- Update Data
- Make Programs Dynamic

---

## 8. What are the rules for naming variables?

### Answer

Rules:

- Must start with a letter or underscore
- Cannot start with a number
- Cannot contain spaces
- Cannot use reserved keywords

Correct:

```python
student_name
age
cgpa
```

Wrong:

```python
1name
student-name
class
```

---

## 10. What is an Integer?

## 12. What is a String?

### Answer

Example:

```python

```

## 13. What is Boolean Data Type?

### Answer

Boolean stores only two values:

```python
True
False
```

Example:

```python

```

---

## 14. How do you check the data type of a variable?

### Answer

Using the `type()` function.

Example:

```python
age = 19

print(type(age))
```

Output:

```python
<class 'int'>
```

---

## 15. What is user input in Python?

### Answer

Python accepts user input using the `input()` function.

Example:

```python
name = input("Enter Name: ")
```

---

## 16. What does input() return?

### Answer

The `input()` function always returns data as a string.

Example:

```python
age = input()
```

Even if the user enters:

```text
19
```

Python stores it as:

```text
"19"
```

---

## 17. What is Type Casting?

### Answer

Type Casting means converting one data type into another.

Example:

```python
age = int(input())
```

---

## 18. How do you convert String to Integer?

### Answer

Using `int()`.

Example:

```python

```

---

## 19. How do you convert String to Float?

### Answer

Using `float()`.

Example:

```python

```

## 25. What is the difference between = and == ?

### Answer

| Operator | Meaning |
|-----------|-----------|
| = | Assignment |
| == | Comparison |

Example:

```python
x = 10
```

Assigns value.

Example:

```python
x == 10
```

Checks equality.
