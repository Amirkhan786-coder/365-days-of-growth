Q1. Which keyword is commonly used with a context manager?

A. with
B. context
C. manage
D. using

Answer: A


Q2. Which method is called when entering a custom context manager?

A. __start__()
B. __enter__()
C. __begin__()
D. __open__()

Answer: B


Q3. Which method is called when leaving a custom context manager?

A. __close__()
B. __end__()
C. __exit__()
D. __stop__()

Answer: C


Q4. Which module provides the @contextmanager decorator?

A. context
B. contextlib

D. manager

A. Creating classes
B. Managing resources safely

D. Sorting data

B. A database

B. package.py
