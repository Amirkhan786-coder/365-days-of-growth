# 🧮 Calculator Using Functions

## 📌 Project Overview

The **Calculator Using Functions** is a simple Python console application that performs basic mathematical operations using **User Defined Functions**.

Each mathematical operation is written as a separate function, demonstrating the concepts of modular programming and code reusability.
