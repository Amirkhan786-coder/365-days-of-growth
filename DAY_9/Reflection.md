# 💡 What I Learned Today

Today, I learned one of the most important concepts in Python—**Functions**.

Functions help write reusable, organized, and efficient code. Instead of repeating the same code multiple times, I can create a function once and call it whenever needed.

I learned how to create functions, pass parameters and arguments, use return statements, work with local and global variables, understand variable scope, create recursive functions, and use lambda functions for writing short anonymous functions.

I also practiced different types of arguments like positional, keyword, default, *args, and **kwargs.
