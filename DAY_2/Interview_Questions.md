### Answer

Example

```python

age = 19
```

Examples

- float
- str

- tuple
- dictionary
- set

# Q4. What is an Operator?

### Answer

An Operator is a symbol that performs operations on values.

Example

```python
10 + 5
```

Here `+` is an operator.

---

# Q5. How many types of Operators are available in Python?

### Answer

1. Arithmetic
2. Assignment
3. Comparison
4. Logical
5. Identity
6. Membership
7. Bitwise

---

# Q6. Difference between = and == ?

### Answer

`=` is Assignment Operator.

```python
a = 10
```

`==` is Comparison Operator.

```python
a == 10
```

It returns True or False.

---

# Q7. Difference between / and // ?

### Answer

`/` returns Float Division.

Example

```python
10 / 3 = 3.3333
```

`//` returns Floor Division.

```python
10 // 3 = 3
```

---

# Q8. What is Modulus Operator?

### Answer

The `%` operator returns the remainder.

Example

```python
10 % 3
```

Output

```
1
```

---

# Q9. What is Exponent Operator?

### Answer

The `**` operator calculates power.

Example

```python
2 ** 5
```

Output

```
32
```

---

Functions

```python

```

# Q13. What is a Conditional Statement?

### Answer

Conditional Statements help the computer make decisions.

Example

```python
if age >= 18:
    print("Eligible")
```

---

# Q14. What is if Statement?

### Answer

It executes only when the condition is True.

Syntax

```python
if condition:
    statement
```

---

# Q15. What is if-else?

### Answer

if executes when the condition is True.

else executes when the condition is False.

---

# Q16. What is elif?

### Answer

elif means "Else If".

It is used when multiple conditions are checked.

---

# Q17. What is Nested if?

### Answer

An if statement inside another if statement.

---

# Q18. Difference between if and elif?

### Answer

if starts the condition.

elif checks additional conditions if previous ones are False.

---

# Q19. What are Logical Operators?

### Answer

Logical Operators combine multiple conditions.

- and
- or
- not

---

# Q20. Difference between and & or?

### Answer

and

All conditions must be True.

or

At least one condition must be True.

---

# Q21. What is Identity Operator?

### Answer

Identity Operators check whether two variables refer to the same object.

Operators

```
is

is not
```

---

# Q22. What is Membership Operator?

### Answer

Membership Operators check whether a value exists inside a sequence.

Operators

```
in

not in
```

---

# Q23. What is Indentation?

### Answer

Indentation means proper spacing before a block of code.

Python uses indentation to define code blocks.

---

# Q24. What happens if indentation is wrong?

Python raises an IndentationError and the program will not run.
