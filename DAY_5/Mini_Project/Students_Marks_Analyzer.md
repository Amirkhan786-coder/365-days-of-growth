# 📊 Student Marks Analyzer

## 📌 Objective

Build a Python application that stores student marks using Lists and calculates results automatically.

---

## 🛠 Technologies Used

- Python
- Lists
- Loops
- Conditional Statements

---

## ✨ Features

- Student Name
- Marks Input
- Total Marks
- Average Marks
- Percentage
- Highest Marks
- Lowest Marks
- Grade
- Pass / Fail

---

## 📸 Sample Output

Student Name : Amir

Marks : [90,95,88,91,89]

Percentage : 90.6%

Grade : A+

Result : PASS
