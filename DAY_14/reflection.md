## 💡 What I Understood

I understood that a **class is like a blueprint** and an **object is an instance created from that blueprint**.

For example:

```text
Student → Class

Amir    → Object
Rahul   → Object
Priya   → Object
```

I also understood that `self` is used to refer to the current object.

---

## 🔥 Most Important Concept

The most important concept I learned today is:

```python
class Student:

    def __init__(self, name, marks):
        self.name = name
        self.marks = marks
```

Here:

```text
Student       → Class
__init__()    → Initialization method
self.name     → Instance Attribute
self.marks    → Instance Attribute
```
