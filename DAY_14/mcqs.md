# 📝 Day 14 — Python OOP MCQs

## Topic: Classes, Objects, self, __init__, Attributes & Methods

---

### Q1. What does OOP stand for?

A. Object Oriented Programming  
B. Object Operating Program  
C. Online Object Programming  
D. Open Oriented Programming  

**Answer: A. Object Oriented Programming**

---

### Q2. What is a class?

A. A variable  
B. A blueprint for creating objects  
C. A loop  
D. A module  

**Answer: B. A blueprint for creating objects**

---

### Q3. What is an object?

A. A function  
B. A variable only  
C. An instance of a class  
D. A package  

**Answer: C. An instance of a class**

---

### Q4. Which keyword is used to create a class?

A. `function`  
B. `define`  
C. `class`  
D. `object`  

**Answer: C. `class`**

---

### Q5. Which method is commonly used as a constructor in Python?

A. `start()`  
B. `main()`  
C. `__init__()`  
D. `constructor()`  

**Answer: C. `__init__()`**

---

### Q6. What does `self` represent?

A. The class  
B. The current object  
C. The parent class  
D. The module  

**Answer: B. The current object**

---

### Q7. Which operator is used to access object attributes?

A. `+`  
B. `#`  
C. `.`  
D. `@`  

**Answer: C. `.`**

---

### Q8. What is a method?

A. A function inside a class  
B. A variable outside a class  
C. A package  
D. A data type  

**Answer: A. A function inside a class**

---

### Q9. Which code correctly creates an object?

```python
class Student:
    pass
```

### Q10. What will this code print?

```python
class Student:

    def __init__(self):
        print("Hello")


student1 = Student()
```

A. Nothing  
B. Error  
C. Hello  
D. Student

### Q11. Which is an instance variable?

```python
class Student:

    def __init__(self, name):
        self.name = name
```

A. `Student`  
B. `__init__`  
C. `self.name`  
D. `name` only  

**Answer: C. `self.name`**

---

### Q12. What is a class variable?

A. A variable shared by objects of a class  
B. A variable inside a function only  
C. A local variable  
D. A loop variable  

**Answer: A. A variable shared by objects of a class**

---

### Q13. Which one is a class variable?

### Q14. Can one class create multiple objects?

A. Yes  
B. No  
C. Only two

### Q15. What is the purpose of `__init__()`?

A. Delete an object  
B. Initialize object data  
C. Stop a program

**Answer: B. Initialize object data**

---

### Q16. What will this code output?

```python
class Student:

    def __init__(self, name):
        self.name = name

print(student1.name)
```

A. Student  
B. name  
C. Amir  
D. Error  

**Answer: C. Amir**

### Q17. Which statement is correct?

A. A class is an instance of an object  
B. An object is an instance of a class  
C. A method is a class  
D. `self` creates a class  

**Answer: B. An object is an instance of a class**

### Q18. Which method is correctly defined?

A.

```python
def display():
    pass
```

B.


### Q19. What happens when an object is created?
