# 💡 Key Concepts

## Class

A class is a blueprint for creating objects.

```python
class Student:
    pass
```

## Object

An object is an instance of a class.

```python
student1 = Student()
```

## self

`self` refers to the current object.

```python
class Student:

    def show(self):
        print("Student")
```

## __init__()

`__init__()` is used to initialize object data.

```python
class Student:

    def __init__(self, name):
        self.name = name
```
