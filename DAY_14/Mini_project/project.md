# 🎓 Day 14 Mini Project — Student Gradebook

## 📌 Project Name

**Student Gradebook**

---

## 🎯 Objective

The objective of this project is to create a simple Student Gradebook using Python Object-Oriented Programming.

The project will store student information, calculate grades, calculate average marks, and display student records.

---

## 🧠 Concepts Used

This project uses:

- Classes
- Objects
- `__init__()`
- `self`
- Instance Variables
- Methods
- Lists
- Loops
- Conditional Statements
- Functions through Class Methods

---

## ✨ Features

The program can:

1. Add students
2. Store student name
3. Store student marks
4. Calculate grade
5. Calculate average marks
6. Display student details
7. Display all students
8. Count total students
9. Find the highest scorer
10. Exit the program
