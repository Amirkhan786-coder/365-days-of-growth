## Final Mini Project

# Student Result Management System

The final project is a Python application that manages student
results and generates a performance report.

## Features

The application can:

- Store student information.
- Store subject marks.
- Validate marks.
- Handle invalid data.
- Calculate total marks.
- Calculate average marks.
- Assign grades.
- Determine PASS/FAIL status.
- Rank students.
- Filter passed students.
- Generate a result report.
- Save the report to a text file.

## Technologies Used

- Python 3
- `dataclasses`
- `functools`
- `contextlib`
