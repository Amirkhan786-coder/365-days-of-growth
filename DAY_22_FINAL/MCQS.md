DAY 22 — PYTHON ADVANCED
30 MCQs


Q1. Which keyword is used to handle an exception?

A. error
B. catch
C. except
D. handle

Answer: C. except


Q2. Which block always executes whether an exception occurs
or not?

A. try
B. except
C. else
D. finally

Answer: D. finally


Q3. Which keyword is used to manually generate an exception?

A. throw
B. raise
C. error
D. exception

Answer: B. raise


Q4. Which special method returns an iterator from an object?

A. __next__()
B. __iter__()
C. __iterator__()
D. __loop__()

Answer: B. __iter__()


Q5. Which keyword is mainly used to create a generator?

A. generate
B. return
C. yield
D. generator

Answer: C. yield


Q6. What does a generator provide?

A. All values at once
B. Values one at a time
C. Only strings
D. Only numbers

Answer: B. Values one at a time


Q7. What is the main purpose of a decorator?

A. Delete a function
B. Modify or extend function behavior
C. Create a database
D. Stop a loop

Answer: B. Modify or extend function behavior


Q8. Which syntax is commonly used to apply a decorator?

A. #
B. @
C. &
D. $

Answer: B. @


Q9. Which statement is commonly used with context managers?

A. if
B. for
C. with
D. switch

Answer: C. with


Q10. Which methods are commonly used to create a custom context
manager?

A. __start__() and __stop__()
B. __open__() and __close__()
C. __enter__() and __exit__()
D. __begin__() and __end__()

Answer: C. __enter__() and __exit__()


Q11. Which module provides the @contextmanager decorator?

A. contextlib
B. context
C. manager
D. resources

Answer: A. contextlib


Q12. What is a Python module?

A. A database
B. A Python file containing reusable code
C. A loop
D. A compiler

Answer: B. A Python file containing reusable code


Q13. What is a package?

A. A collection of related modules
B. A single variable
C. A function
D. A loop

Answer: A. A collection of related modules


Q14. Which statement imports a specific function?

A. import function from module
B. from module import function
C. import module.function
D. include function

Answer: B. from module import function


Q15. What is the purpose of:

if __name__ == "__main__":

A. Handle exceptions
B. Start a loop
C. Run code when the file is executed directly
D. Import a package

Answer: C. Run code when the file is executed directly


Q16. What is the main purpose of type hints?

A. Automatically enforce types
B. Improve readability and tooling
C. Increase CPU speed
D. Replace functions

Answer: B. Improve readability and tooling


Q17. Do Python type hints normally enforce types at runtime?

A. Yes, always
B. No
C. Only for integers
D. Only for classes

Answer: B. No


Q18. Which decorator is used to create a dataclass?

A. @class
B. @data
C. @dataclass
D. @structure

Answer: C. @dataclass


Q19. What is a dataclass mainly useful for?

A. Storing and representing data
B. Creating loops
C. Handling exceptions
D. Managing files

Answer: A. Storing and representing data


Q20. Which function creates a small anonymous function?

A. def
B. lambda
C. anonymous
D. function

Answer: B. lambda


Q21. What does map() generally do?

A. Select elements
B. Transform elements
C. Delete elements
D. Sort elements

Answer: B. Transform elements


Q22. What does filter() generally do?

A. Select elements based on a condition
B. Transform every element
C. Combine all elements
D. Reverse a list

Answer: A. Select elements based on a condition


Q23. Where is reduce() available?

A. itertools
B. functools
C. collections
D. operators

Answer: B. functools


Q24. What does reduce() generally produce?

A. Multiple lists
B. A single accumulated result
C. A dictionary only
D. A generator only

Answer: B. A single accumulated result


Q25. What does enumerate() provide?

A. Only values
B. Only indexes
C. Indexes and values
D. Keys and values

Answer: C. Indexes and values


Q26. What does zip() do?

A. Compresses a file
B. Combines elements from multiple iterables
C. Sorts a list
D. Removes duplicates

Answer: B. Combines elements from multiple iterables


Q27. Which copy can share nested objects with the original?

A. Deep copy
B. Shallow copy
C. Full copy
D. Complete copy

Answer: B. Shallow copy


Q28. Which function creates an independent recursive copy?

A. copy.copy()
B. copy.deep()
C. copy.deepcopy()
D. deepcopy.copy()

Answer: C. copy.deepcopy()


Q29. What does PEP 8 provide?

A. Python's database system
B. Python's style guidelines
C. Python's compiler
D. Python's package manager

Answer: B. Python's style guidelines


Q30. What does DRY stand for?

A. Develop Reliable Yourself
B. Don't Repeat Yourself
C. Data Reuse Yourself
D. Don't Run Yourself

Answer: B. Don't Repeat Yourself
