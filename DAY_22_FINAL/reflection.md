## Iterators and Generators

I revised the difference between iterators and generators.

Generators use the `yield` keyword and produce values one at a
time.

This makes generators useful when working with large amounts
of data because they do not need to store everything in memory
at once.


## Decorators

I revised how decorators can modify or extend the behavior of
functions without changing the original function.

I practiced decorators for:

- Logging
- Function calls
- Validation
- Execution timing


## Context Managers

I learned how context managers safely manage resources.

The `with` statement makes resource handling easier and ensures
that cleanup operations are performed properly.

I also practiced creating custom context managers using:

- `__enter__()`
- `__exit__()`
- `@contextmanager`


## Modules and Packages

I revised how Python code can be divided into modules and

- Organize

## Type Hints

I practiced using type hints for:

- Function parameters
- Return values

Type hints make code easier to understand and provide better

## Dataclasses

I revised how dataclasses simplify classes that mainly store
data.

For example:

```python
@dataclass
class Student:

    name: str
    marks: list[int]
````

Dataclasses reduce unnecessary boilerplate code.

## enumerate() and zip()

I practiced:

### enumerate()

### zip()

Used to combine corresponding values from multiple

## Shallow Copy and Deep Copy

I revised the difference between shallow and deep copying.

### Shallow Copy

Creates a new outer object, but nested objects may still be
shared.

### Deep Copy

Creates independent copies of nested objects as well.
