# 🏆 DAY 006 CHALLENGE

## Student Result Management System

Build a complete program that takes:

```text
Student Name
Roll Number
Marks in 5 Subjects
```

Then calculate:

```text
Total Marks
Percentage
Grade
Pass/Fail
```

### Rules

```text
90+       → A+
80–89     → A
70–79     → B
60–69     → C
40–59     → D
Below 40  → Fail
```

### Important Condition

The student should be marked **Fail** if they score below `40` in even one subject.

### Example

```text
Enter Name: Amir
Enter Roll Number: 101

Enter English Marks: 85
Enter Maths Marks: 92
Enter Physics Marks: 78
Enter Chemistry Marks: 88
Enter Computer Marks: 95
```

Expected output should contain:

```text
================================
       STUDENT RESULT
================================

Name       : Amir
Roll Number: 101

Total      : 438
Percentage : 87.6%
Grade      : A
Result     : PASS

================================
```
