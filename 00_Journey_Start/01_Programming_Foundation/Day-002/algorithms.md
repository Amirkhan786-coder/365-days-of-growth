## Algorithm 3 — Calculate Area of a Rectangle

1. Start
2. Take length
3. Take width
4. Calculate:

Area = Length × Width

5. Display area
6. Stop

## Algorithm 4 — Calculate Average of Three Numbers

1. Start
2. Take three numbers

4. Divide the sum by 3
5. Display the average

## Algorithm 5 — Find the Larger Number

1. Start
2. Take number A
3. Take number B
4. Compare A and B
5. If A is greater, display A
6. Otherwise, display B
7. Stop
