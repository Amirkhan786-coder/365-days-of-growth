# ✅ Day 002 Answers

## Q1. What is programming?

Programming is the process of giving instructions to a computer to perform a specific task.

---

## Q2. Why does a computer need instructions?

A computer needs instructions because it follows the commands provided by a program to perform a task.

---

## Q3. What is problem solving?

Problem solving is the process of understanding a problem and finding a logical solution.

---

## Q4. What is an algorithm?

An algorithm is a clear, step-by-step procedure used to solve a problem.

---

## Q5. What is pseudocode?

Pseudocode is an informal representation of program logic written before actual code.

---

## Q6. Why understand the problem first?

Understanding the problem helps us identify the input, expected output, and the logical steps required to solve it.

---

## Q7. Algorithm to Add Two Numbers

1. Start
2. Input A
3. Input B
4. RESULT = A + B
5. Display RESULT
6. Stop

---

## Q8. Algorithm to Find Square

1. Start
2. Input NUMBER
3. SQUARE = NUMBER × NUMBER
4. Display SQUARE
5. Stop

---

## Q9. Algorithm for Rectangle Area

1. Start
2. Input LENGTH
3. Input WIDTH
4. AREA = LENGTH × WIDTH
5. Display AREA
6. Stop

---

## Q10. Algorithm for Total Marks

1. Start
2. Input marks of three subjects
3. Add all marks
4. Display total
5. Stop

---

## Q11. Algorithm for Average

1. Start
2. Input three numbers
3. Add all numbers
4. Divide the total by 3
5. Display average
6. Stop
