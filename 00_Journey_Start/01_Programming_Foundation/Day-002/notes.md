# 📚 Programming Foundations Notes

## 1. What is Programming?

Programming is the process of giving instructions to a computer to perform a specific task.

A computer cannot understand our intentions automatically. We need to give clear and logical instructions.

### Example: Making Tea

1. Take a cup.
2. Add tea.
3. Add sugar.
4. Add hot water.
5. Mix properly.

Similarly, a computer program contains step-by-step instructions.

---

## 2. What is Problem Solving?

Problem solving means finding a logical way to solve a problem.

### Example

Problem: Find the sum of two numbers.

Steps:

1. Take the first number.
2. Take the second number.
3. Add both numbers.
4. Display the result.

Before writing code, we should understand the problem and identify the required steps.

---

## 3. What is an Algorithm?

An algorithm is a step-by-step procedure used to solve a problem.

### Example: Find the Larger Number

1. Start
2. Take two numbers
3. Compare both numbers
4. Display the larger number
5. Stop

A good algorithm should be clear, logical, and finite.

---

## 4. What is Pseudocode?

Pseudocode is an informal way of writing program logic.

It looks similar to programming instructions but is not actual code.

Example:

START

INPUT number1
INPUT number2

SUM = number1 + number2

DISPLAY SUM

STOP

Pseudocode helps us plan the solution before writing actual code.

## Key Lesson

Syntax can be learned by practice.

But problem-solving improves when we regularly understand, analyze, and solve different problems.

> Don't memorize code. Understand the logic behind it.
