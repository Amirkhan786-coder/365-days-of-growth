## 🧠 What I Learned

### 📦 Variables

A variable is a name used to store data.

Example:

```python
name = "Amir Khan"
age = 20

Here:

name stores text data.
age stores a numerical value.

Variables allow us to store, reuse, and update information in a program.

🔤 Data Types

Python uses different data types to represent different kinds of information.

Data Type	Example	Description
str	"Amir Khan"	Text
int	20	Whole number
float	5.8	Decimal number
bool	True	True or False value

Example:

name = "Amir Khan"
age = 20
height = 5.8
is_student = True
🔍 Checking Data Types

Python provides the type() function to check the data type of a variable.

name = "Amir Khan"
age = 20

print(type(name))
print(type(age))

Output:

<class 'str'>
<class 'int'>
