Which Python module is used for Regular Expressions?

A. regex
B. re
C. regexp
D. pattern

Answer: B. re


# ============================================================
# MCQ 2
# ============================================================

Which function searches for the first match anywhere
in a string?

A. re.match()
B. re.search()
C. re.findall()
D. re.find()

Answer: B. re.search()


# ============================================================
# MCQ 3
# ============================================================

Which function checks for a match only at the beginning
of a string?

A. re.search()
B. re.match()
C. re.fullmatch()
D. re.start()

Answer: B. re.match()


# ============================================================
# MCQ 4
# ============================================================

Which function checks whether the entire string matches
the pattern?

A. re.search()
B. re.match()
C. re.fullmatch()
D. re.complete()

Answer: C. re.fullmatch()

# MCQ 5
# ============================================================

What does re.findall() return?

A. A single match object
B. A list of all matches
