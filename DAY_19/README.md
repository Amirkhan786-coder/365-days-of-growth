# Day 19 — Python Advanced

## Regular Expressions + Collections

Day 19 focuses on advanced Python concepts for text
processing and data organization.

The main focus is on Regular Expressions and the
`collections` module.

---

- `re.search()`

- `re.findall()`
- `re.finditer()`
