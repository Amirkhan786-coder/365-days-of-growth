## 🧠 Most Important Concept

The most important concept for me today was **Inheritance**.

Inheritance allows a child class to reuse functionality from a parent class.

Example:

```python
class Animal:

    def eat(self):
        print("Eating")


class Dog(Animal):

    def bark(self):
        print("Barking")
```

The `Dog` class can use the `eat()` method from `Animal`.
