# 🧠 DAY 15 — Python OOP Part 2
# MCQs

---

## Q1. What is inheritance?

A. Creating a variable  
B. Acquiring properties and methods from another class  
C. Creating a loop  
D. Creating a function  

**Answer: B**

---

## Q2. Which class is inherited from?

A. Child class  
B. Derived class  
C. Parent class  
D. Object class  

**Answer: C**

---

## Q3. Which syntax is used for inheritance?

A. `class Child -> Parent:`  
B. `class Child(Parent):`  
C. `inherit Child(Parent):`  
D. `class Child extends Parent:`  

**Answer: B**

---

## Q4. What does `super()` do?

A. Creates an object  
B. Deletes a class  
C. Accesses parent class functionality  
D. Creates a loop  

**Answer: C**

---

## Q5. What is method overriding?

A. Deleting a method  
B. Changing a variable  
C. Child class providing its own version of a parent method  
D. Creating a new class  

**Answer: C**

---

## Q6. Which inheritance has multiple levels?

A. Single inheritance  
B. Multiple inheritance  
C. Multilevel inheritance  
D. Simple inheritance  

**Answer: C**

---

## Q7. What is multiple inheritance?

A. One class has multiple objects  
B. One child class inherits from multiple parent classes  
C. Multiple methods in one class  
D. Multiple constructors  

**Answer: B**

---

## Q8. What does polymorphism mean?

A. One class only  
B. Multiple variables  
C. Same interface with different behavior  
D. Creating private variables  

**Answer: C**

---

## Q9. Which concept is related to controlling access to data?

A. Inheritance  
B. Encapsulation  
C. Polymorphism  
D. Looping  

**Answer: B**

---

## Q10. Which symbol is commonly used for a private-style attribute?

A. `_`  
B. `__`  
C. `#`  
D. `@`  

**Answer: B**

---

## Q11. What is a getter used for?

A. Updating data  
B. Deleting data  
C. Accessing data  
D. Creating a class  

**Answer: C**

---

## Q12. What is a setter used for?

A. Updating data  
B. Reading only data  
C. Creating an object  
D. Inheriting a class  

**Answer: A**

---

## Q13. Which module provides tools for abstract base classes?

A. `math`  
B. `random`  
C. `abc`  
D. `os`  

**Answer: C**

---

## Q14. Which class is commonly used as the base for abstract classes?

A. `ABC`  
B. `Abstract`  
C. `Base`  
D. `Class`  

**Answer: A**

---

## Q15. Which decorator is used to define an abstract method?

A. `@abstract`  
B. `@abstractmethod`  
C. `@method`  
D. `@override`  

**Answer: B**

---

## Q16. What does `self` refer to?

A. Parent class  
B. Current object  
C. Child class  
D. Module  

**Answer: B**

---

## Q17. Which function can show the Method Resolution Order?

A. `order()`  
B. `method_order()`  
C. `mro()`  
D. `resolution()`  

**Answer: C**

---

## Q18. What is the main benefit of inheritance?

A. Code duplication  
B. Code reusability  
C. Slower execution  
D. More variables  

**Answer: B**

---

## Q19. Which is an example of polymorphism?

A. Dog and Cat both having different `sound()` implementations  
B. Creating a variable  
C. Creating a list  
D. Using a loop  

**Answer: A**

---

## Q20. Which is NOT one of the four major OOP concepts?

A. Encapsulation  
B. Inheritance  
C. Polymorphism  
D. Iteration  

**Answer: D**
