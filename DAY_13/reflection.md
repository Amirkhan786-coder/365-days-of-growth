# 💻 Practical Learning

I practiced creating my own Python modules.

For example:

```python
# calculator.py

def add(a, b):
    return a + b
```

Then I imported the module into another Python file:

```python
import calculator

print(calculator.add(10, 5))
```

This helped me understand how code can be reused instead of being written again and again.

# 📦 Packages

I also learned that a package can be used to organize related modules.

Example:

```text
project/
│
├── main.py
│
└── student/
    ├── __init__.py
    ├── details.py
    └── marks.py
```

This structure makes large projects easier to understand and maintain.

---

# 🛠️ pip and External Packages

I learned about `pip`, Python's package installer.

Example:

```bash
pip install numpy
```

I also learned about:

```text

```

which can be used to store project dependencies.
