## Q1. What is a Python module?

A. A database  
B. A Python file containing reusable code  
C. An operating system  
D. A compiler  

**Answer: B. A Python file containing reusable code**

---

## Q2. What is the extension of a Python module?

A. `.java`  
B. `.cpp`  
C. `.py`  
D. `.html`  

**Answer: C. `.py`**

---

## Q3. Which keyword is used to import a module?

A. include  
B. import  
C. require  
D. using  

**Answer: B. import**

---

## Q4. Which statement imports the math module?

A. `include math`  
B. `using math`  
C. `import math`  
D. `load math`  

**Answer: C. `import math`**

---

## Q5. Which function returns the square root of a number?

A. `math.square()`  
B. `math.sqrt()`  
C. `math.root()`  
D. `math.sq()`  

**Answer: B. `math.sqrt()`**

---

## Q6. What is the output?

```python
import math

print(math.sqrt(25))
```

A. `5`  
B. `5.0`  
C. `25`  
D. Error  

**Answer: B. `5.0`**

---

## Q7. Which module is used for random number generation?

A. `math`  
B. `random`  
C. `number`  
D. `rand`  

**Answer: B. `random`**

---

## Q8. Which function generates a random integer between two values?

A. `random.number()`  
B. `random.randint()`  
C. `random.integer()`  
D. `random.randomint()`  

**Answer: B. `random.randint()`**

---

## Q9. Which function randomly selects an item from a sequence?

A. `random.select()`  
B. `random.choice()`  
C. `random.item()`  
D. `random.pick()`  

**Answer: B. `random.choice()`**

---

## Q10. Which function randomly rearranges a list?

A. `random.change()`  
B. `random.shuffle()`  
C. `random.rearrange()`  
D. `random.randomize_list()`  

**Answer: B. `random.shuffle()`**

## Q11. Which module is used for date and time operations?

A. `timeDate`  
B. `calendarTime`  
C. `datetime`  
D. `dateTimeModule`  

**Answer: C. `datetime`**

---

## Q12. Which statement gets today's date?

A. `datetime.today()`  
B. `datetime.date.today()`  
C. `datetime.current()`  
D. `datetime.getdate()`  

**Answer: B. `datetime.date.today()`**

## Q13. Which module is used to interact with the operating system?

A. `system`  
B. `os`  
C. `operating`  
D. `computer`  

**Answer: B. `os`**

---

## Q14. What does `os.getcwd()` return?

A. Python version  
B. Current working directory  
C. Current username  
D. Current date  

**Answer: B. Current working directory**

---

## Q15. Which function lists files and folders in a directory?

A. `os.files()`  
B. `os.show()`  
C. `os.listdir()`  
D. `os.display()`  

**Answer: C. `os.listdir()`**

---

## Q16. Which module provides access to Python system-specific functionality?

A. `system`  
B. `python`  
C. `sys`  
D. `runtime`  

**Answer: C. `sys`**

---

## Q17. Which statement displays the Python version?

A. `sys.version`  
B. `python.version`  
C. `os.version()`  
D. `version.python()`  

**Answer: A. `sys.version`**

---

## Q18. What is a package?

A. A single Python variable  
B. A collection of related Python modules  
C. A Python keyword  
D. A database  

**Answer: B. A collection of related Python modules**

---

## Q19. Which file is commonly associated with a regular Python package?

A. `main.py`  
B. `package.py`  
C. `__init__.py`  
D. `start.py`  

**Answer: C. `__init__.py`**

---

## Q20. What does `from math import sqrt` do?

A. Imports the entire Python language  
B. Imports only `sqrt` from `math`  
C. Creates a new module  
D. Deletes the math module  

**Answer: B. Imports only `sqrt` from `math`**

---

## Q21. What is the purpose of `as` in an import statement?

A. To delete a module  
B. To rename an imported module locally  
C. To create a package  
D. To install a package  

**Answer: B. To rename an imported module locally**

---

## Q22. What is the output?

```python
import math as m

print(m.sqrt(16))
```

A. `4`  
B. `4.0`  
C. `16`  
D. Error  

**Answer: B. `4.0`**

---

## Q23. Which command installs a Python package?

A. `python install package`  
B. `pip install package`  
C. `install pip package`  
D. `package install`  

**Answer: B. `pip install package`**

---

## Q24. Which command displays installed packages?

A. `pip packages`  
B. `pip showall`  
C. `pip list`  
D. `pip installed`

---

## Q25. Which command uninstalls a package?

A. `pip remove package`

## Q26. What is `requirements.txt` used for?

A. Storing Python code  
B. Storing project dependencies  
C. Storing passwords  
D. Storing images  

**Answer: B. Storing project dependencies**

---

## Q27. Which command installs packages listed in `requirements.txt`?

A. `pip install requirements`  
B. `pip install -r requirements.txt`

## Q28. What is `__name__`?

A. A normal user-defined variable  
B. A special built-in variable  
C. A package  
D. A function  

**Answer: B. A special built-in variable**

---

## Q29. What is the value of `__name__` when a Python file is run directly?

A. `main`  
B. `python`  
C. `__main__`  
D. `__start__`  

**Answer: C. `__main__`**

---

## Q30. Why is this statement commonly used?

```python
if __name__ == "__main__":
```

A. To install packages  
B. To run code only when the file is executed directly  
C. To create a module  
D. To delete a package  

**Answer: B. To run code only when the file is executed directly**

---

## Q31. What does `sys.path` contain?
